# BabyBloom — Frontend-only project

**Project title:** Baby Shower Party Games and Birth Milestone Prediction Management System

This version follows the supplied assignment brief: a responsive, interactive frontend application that does **not** rely on backend services.

## Open the website
1. Extract `BabyBloom_Frontend_Only.zip`.
2. Open the extracted `BabyBloom_Frontend_Only` folder.
3. Double-click `index.html` to open it in Chrome or Edge.
4. Add sample guest entries using the form.

No Node.js, npm, database, server, or VS Code extension is required. You can optionally open the folder in VS Code and use Live Server.

## Features
- Guess the Birth Date
- Baby Weight Predictor
- Baby Name Suggestions
- Advice for Parents
- Guest memory board with filters and search
- Live entry counters
- Browser storage using localStorage
- Download entries as a JSON keepsake
- Print the keepsake
- Responsive layout for mobile and desktop

## Important
Entries are stored in the browser on the current device only. They do not sync between devices or browsers. Download a JSON keepsake copy to back them up. The Clear button removes local demo entries after confirmation.

## Syllabus mapping
- **HTML:** HTML5 structure, headings, paragraphs, links, buttons, forms, inputs, labels and metadata.
- **Semantic HTML & Forms:** header, nav, main, section, article, footer, form controls, validation, accessible labels and status messages.
- **CSS:** selectors, variables, colours, backgrounds, typography, box model, Flexbox, Grid, pseudo-classes, responsive media queries, transitions and animations.
- **JavaScript:** const, let, strings, numbers, booleans, operators, conditions, functions, arrays, objects, DOM events, JSON and localStorage.

## Scope
The website is intentionally frontend-only, as required in the project brief. Date and weight predictions are for entertainment and are not medical predictions or advice.
